FAQ / COMMON QUESTIONS TO ADDRESS
================================================================================

Q: What is APRS?
A: Automatic Packet Reporting System - real-time tactical digital communications
   protocol for amateur radio.

Q: What is APRS-IS?
A: APRS Internet Service - global network of APRS servers connected via internet.

Q: Which platforms are supported?
A: AMD64 (Intel/AMD servers), ARM64 (Raspberry Pi 4/5, ARM servers, Apple Silicon),
   and ARMv7 (Raspberry Pi 2/3). Docker automatically selects the correct architecture
   for your device.

Q: Will this work on Raspberry Pi?
A: Yes! Fully tested on Raspberry Pi 2, 3, 4, and 5. Just pull and run - Docker
   automatically uses the correct ARM image for your Pi model.

Q: Do I need a ham radio license?
A: To transmit APRS data via RF, yes. To run a server and gateway, depends on
   your use case. Read-only monitoring doesn't require a license.

Q: Can I use this for commercial purposes?
A: APRS is primarily for amateur radio (non-commercial). Check local regulations.

================================================================================
MULTI-ARCHITECTURE BUILD NOTES
================================================================================

This image is built using Docker buildx with multi-platform support.

Build Command:
./push-to-dockerhub.sh

Platforms Built:
- linux/amd64 (x86-64)
- linux/arm64 (ARMv8 / aarch64)
- linux/arm/v7 (ARMv7 / armv7l)

Build Time:
- Total: ~15-20 minutes for all platforms
- AMD64: ~3-5 minutes (native)
- ARM64: ~5-7 minutes (QEMU emulation)
- ARMv7: ~5-7 minutes (QEMU emulation)

Image Sizes (compressed):
- AMD64: ~4.8 MB
- ARM64: ~4.6 MB
- ARMv7: ~4.5 MB

The buildx command creates a manifest list that allows Docker to automatically
select the correct architecture when users pull the image.

Verify manifest list:
docker buildx imagetools inspect bd5rv/aprsc:latest

For detailed instructions, see:
https://github.com/bd5rv/aprsc-docker/blob/main/MULTI_ARCH.md
